# 在 Claude Link 中使用正在运行的 Codex / Qoder CN

进入“CLI”，点击右上角 `⋮`，在悬浮菜单中选择“恢复 Codex 对话”或“恢复 Qoder 对话”。运行中的交互终端排在列表前面，包括还没有发送首条消息的新终端。点击“原终端使用中 · 点击接入”即可继续操作。点击顶部当前窗口名可弹出窗口列表进行切换；新增、恢复、扫码及移除等操作均按需弹出，顶部仅占一行。

已有 tmux 窗口会共享现有窗口与进程，桌面连接仍可使用。普通 SSH 终端会在点击接入时转入持久 tmux 窗口，保留原进程、子进程、工作目录和对话编号；原 SSH 连接随后不再收发这个终端的内容。手机连接关闭、切换窗口或暂时断网不会结束该终端。共享窗口的悬浮菜单提供“复制桌面连接”，在新的 SSH 连接粘贴后即可从桌面共享同一终端。

“移除”共享窗口只删除手机入口，终端继续运行，之后可从恢复列表再次接入。手机自己新建的普通 CLI 窗口沿用原有“删除并结束”行为。两种 CLI 合计仍为最多 6 个手机窗口。

普通 SSH 接入需要 Linux、tmux 和 reptyr。通过 SSH 创建的 PTY 需要 root 执行 `reptyr -T`，普通用户须有对应的免密 sudo 权限；应用不会安装工具、修改 sudoers 或降低系统 ptrace 设置。74 已有相关工具与权限。服务器不满足条件或终端已退出时，会显示具体原因。恢复列表、终端识别只检查当前 SSH 用户的交互 CLI，不接入自动执行、管道、后台作业或其他用户的终端。进程编号、启动时间和终端设备会在接入前再次核对。

在普通 SSH shell 中启动的 CLI 会通过其同用户启动 shell 转接。个别直接以 CLI 替代 SSH shell 主进程的启动方式，接入工具可能无法完成转接；此时会提示“终端仍在接入中”，应保留原 SSH 连接，不会另起同一对话。已有 tmux 窗口可直接共享。接入确认后才允许手机打开共享窗口。

普通 SSH 迁移无法复制原终端客户端已经保存的屏幕滚动历史。对话文件仍保留，迁移后的输出会进入共享窗口的滚动历史。接入通过 [reptyr 的 TTY-stealing 模式](https://github.com/nelhage/reptyr/blob/master/reptyr.1) 转交原 PTY 的输入输出，手机不会另外恢复一个进程来同时写同一条对话。
