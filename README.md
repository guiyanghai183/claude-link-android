# Claude Link

Claude Link 是一个通过局域网 SSH 安全控制服务器 Claude Code 的 Android 客户端。

GitHub 仓库：<https://github.com/guiyanghai183/claude-link-android>

## 已实现

- 多服务器管理：IP、端口、用户名和首次登录密码。
- 首次连接后生成手机专用 RSA 密钥，私钥由 Android Keystore 加密保存，服务器密码不落盘。
- SSH 主机密钥首次固定，后续连接检测服务器身份变化。
- SSH 本地端口转发；配套服务只监听服务器 `127.0.0.1:18765`。
- VPN 网络优先路由、SSH 保活、网络切换感知与后台持续自动重连；应用重启后会恢复上次使用的服务器，无需返回服务器页手动连接。
- Claude Code 流式 JSON 多轮会话、状态同步、中断和断线后恢复。
- Claude Code 默认使用原生 Auto Review 权限模式，常规安全操作自动审查并继续；真正需要升级权限的高风险操作仍会在手机显示工具、命令和影响路径，供用户允许或拒绝。
- 服务器目录浏览与项目目录挂载：快捷入口只显示 SSH 用户主目录和 `/` 根目录，可逐级浏览，也可直接输入 `/sdc` 等绝对路径；输入绝对路径时会联想当前 SSH 用户有权限进入的目录。
- 项目页支持两种会话：选择服务器目录后，可创建 Claude 对话或直接进入该目录的 SSH 远程终端对话。
- 远程终端使用持续 PTY 会话，支持实时输出、`Ctrl+C`、`Ctrl+D`、命令历史和中文输入法整段提交；输入框保留足够的文字基线高度，输入法展开时不会裁掉英文、中文组合文字或光标的下半部分，同时保留尚未发送的草稿并让最新终端输出保持可见。交互程序输入不会写入聊天记录。
- 聊天历史默认保留 7 天；星标对话永久保存。
- PDF、CSV 等非媒体实验产物仍可自动发现；图片和视频不再通过递归目录扫描自动发送，避免把依赖库、缓存、图标或无关项目素材批量加入聊天。
- Claude 可调用内置图片与视频交付工具，只把当前请求直接相关、经明确选择的真实图片、视频文件或视频直链显示到聊天中；旧视频文本链接协议仍兼容。
- 每个项目同一时间只运行一个 Claude 回合，消息带幂等 ID，会话切换和项目切换相互隔离。
- 服务器文件浏览器支持当前 SSH 用户有权读取的全文件系统目录、隐藏项、图片、视频与常见文本文件直接预览。
- Claude 项目对话不内置语音输入按钮；研记来电功能在用户配对后才监听，并仅在实时语音通话接听时申请麦克风权限。
- 原“GPU”入口更名为“算力”；进入算力中心后先选择“GPUQ 任务”或“NVIDIA 显卡”，两级页面使用统一的彩色状态卡。NVIDIA 计算进程会显示服务器用户和已运行时间；队列读取严格只读，不会提交、取消或修改任务。
- GPUQ 任务详情兼容新增 CPU/I/O 列、监控摘要及窄终端紧凑卡片；新增监控字段不会再使整个任务列表退化为不可用。
- 原 DeepSeek 对话入口现为专用 Codex 命令行窗口页；点击 `+` 立即创建一个独立 Codex CLI，最多同时保留 6 个窗口。
- 每个 Codex 窗口由服务器端独立 tmux 会话承载；切换窗口、切换页面、关闭应用或手机网络短暂断开不会结束 Codex。应用按服务器记住上次选中的 Codex 窗口和页面，下次打开并恢复 SSH 后会重新附着同名 tmux 会话；删除窗口时才结束对应会话。
- 创建 Codex 窗口时会把已解析的 Codex CLI 路径显式传入 tmux，并检查会话是否在启动后保持存活；启动失败会显示明确错误，不再退化为 `can't find session`。
- Codex 窗口按手机屏幕动态调整终端行列数，对高频终端输出进行后台批量解析和限频刷新；终端区可上下拖动查看当前对话的回滚历史，手动上滑后不会被新输出强制拉回底部，并可点击“回到底部”恢复自动跟随。重新连接同一窗口时会从服务器 tmux 恢复最近 1,200 行历史。
- Codex 页支持“扫码接力”：扫描 Codex/ChatGPT 生成的 `claudelink://handoff/v1` 二维码后，先预览来源、标题和接力摘要，经用户确认再创建窗口。扫码画面左上角提供明确的“返回”按钮，也支持系统返回键或手势取消扫码。二维码含真实 Codex UUID 且当前服务器存在该会话时执行 `codex resume`；跨主机或 ChatGPT 对话则自动以摘要创建新会话。
- 快捷键栏最前面依次是 Alt+↑、1、2、3、`/permissions`、`/model`，后续是 Esc、Tab、方向键、`^C`、`^D`。输入区支持多行草稿，在中文输入法候选词尚未确认时禁止发送，成功提交后会立即收起输入法。
- 旧版网页 OCR 附加入口不再展示；已有 Claude 项目对话及文件交付仍保留。
- GitHub Releases 应用内更新：启动自动检查、发布说明、SHA-256 校验和系统安装确认。
- 浅色/深色苹果风格 Compose 界面。
- 研记语音确认：在“服务器”页配对研记后，应用通过前台监听服务接收来电，使用来电铃声、振动和接听界面提醒。问题语音由研记服务器调用百炼合成，手机直接播放；配置百炼 Realtime 后可进行实时语音问答。研记配对码只授予接听、回复和音频传输权限。

## 研记来电

1. 在研记任意实验记录的“语音确认”中打开“配对与模型设置”，生成 Claude Link 配对码。
2. 在 Claude Link 的“服务器”页找到“研记来电”，填入研记 HTTPS 地址及配对码，点击“配对并开启来电”。允许系统通知权限。
3. 在研记网页填入百炼 Realtime WSS 地址和 API Key。测试来电接听后，研记用同一密钥合成问题语音；手机播放后可选择“声音清楚”或“声音不清楚”。未填写密钥时仍可测试来电提醒，但不能播放问题。
4. 如需自由语音问答，发起“实时语音询问”。接听后手机播放问题，随后自动打开麦克风；首次使用会申请麦克风权限。录音与播放使用 16 kHz/24 kHz PCM 音频，研记服务器转发至百炼，密钥不会传到手机。

来电监听会显示一条常驻通知。鸿蒙系统可能另有后台运行和锁屏弹出限制；来电在锁屏上的实际表现应以手机测试为准。

## 远程终端对话

1. 连接服务器后进入“项目”，点击右上角 `+`。
2. 从 `gyhai` 或 `/` 根目录逐级选择，也可直接输入 `/sdc` 等绝对路径；键入路径前缀或以 `/` 结尾时会显示可进入的子目录联想。
3. 点击“挂载当前目录”，然后选择“Claude 对话”或“远程终端对话”。
4. 终端对话通过现有安全 SSH 连接在服务器上打开 PTY，并首先进入所选目录；它不会在 Android 手机上执行本地命令。

终端空闲时，输入框提交的是一条服务器命令，命令和输出会保存在对应终端对话中。远程程序尚未结束时，输入框会切换为标准输入模式；此时内容直接送入远程程序但不保存，避免记录 `sudo` 密码等敏感输入。所有文本先由 Android 输入法完成拼音、候选词或语音输入，再以 UTF-8 整段发送到服务器。

终端底部采用紧凑输入栏，只保留 SSH 状态、`^C`、`^D`、命令历史、输入框和发送键；空闲输入框不再显示“命令”占位文字，当前目录仍显示在对话顶部，不在输入栏重复展示。

终端对话适合普通 Shell、脚本、Python REPL 和需要标准输入的命令。聊天式输出会清理 ANSI 控制码，但不完整模拟 `vim`、`top` 等全屏 VT 终端界面。

## Codex / ChatGPT 对话接力

1. 在 Codex 或 ChatGPT 对话中说“生成该对话的二维码供我在 Claude Link 中使用”。`Claude Link 对话接力` 插件会把当前目标、已完成证据、约束和下一步压缩进二维码，不上传到临时中转服务器。
2. 在 Claude Link 的“Codex”页点击“扫码接力”，扫描二维码并核对预览；如需退出，可点击左上角“返回”或使用系统返回键/手势。点击“继续回答”后才会创建新的 Codex 窗口。
3. 若二维码含真实 Codex 会话 UUID，Claude Link 会先检查当前 SSH 服务器的 `~/.codex/sessions`；存在时恢复原会话，不存在时使用接力摘要启动新会话。ChatGPT 对话和跨主机接力始终采用摘要启动。

二维码是自包含数据，任何能扫描它的人都能读取其中的接力摘要。生成端会拦截常见密钥格式，但仍不应把密码、Cookie、API Key、访问令牌或无关个人信息放入摘要。

## Claude 图片、视频与权限

- 要让 Claude 显示图片，可明确说“把 `results/chart.png` 这张图发送到手机聊天中”，或“生成图表后只发送最终图”。Claude 会对选中的单张图片调用内置交付工具。
- 要让 Claude 显示视频，可明确说“把 `outputs/demo.mp4` 发送到手机聊天中”，或提供无需登录即可访问的真实 HTTP/HTTPS 视频直链。
- 图片和视频必须位于当前挂载的项目目录内；Claude Link 会校验文件是否存在、扩展名和基本文件头，再登记到当前聊天。文件浏览器中的手动预览不受此限制。
- 应用启动 Claude Code 时直接传入 `--permission-mode auto`。这不是通过 `CLAUDE.md` 模拟审批；Auto Review 会自动处理常规操作，而 Claude Code 仍可能针对高风险或需要额外权限的操作发出手机审批请求。
- Claude 与远程终端的消息输入框均采用紧凑尺寸；Claude 输入栏已移除语音按钮，但仍完整支持普通 Android 输入法及输入法自带的语音功能。
- 每段对话默认折叠顶部标题和项目目录，只保留返回、展开触点和星标按钮。轻触顶部中央触点即可展开，轻触消息区空白处会再次折叠。

## 项目结构

- `android/`：Kotlin + Jetpack Compose Android 应用。
- `server/`：Python 标准库实现的服务器桥接服务及单元测试。
- `server/install.sh`：可选的 Linux 用户级 systemd 安装脚本。

## 构建

需要 JDK 17、Android SDK 36 和 Build Tools 35.0.0。

```powershell
cd android
./gradlew.bat :app:assembleDebug
```

服务器端不需要额外 Python 包。应用会通过 SFTP 校验并同步内置的 `mobile_claude_server.py`，也可以手动执行：

```bash
cd server
bash install.sh mobile_claude_server.py
```

## 数据保留

服务端 SQLite 历史位于 `~/.local/share/mobile-claude/history.sqlite3`。未星标对话按最后活动时间保留 7 天；清理时也会删除对应的 Claude 会话记录，但不会删除项目中的实验文件。星标对话不参与自动清理。

## GitHub 自动发布

推送形如 `v0.3.4` 的版本标签后，GitHub Actions 会测试项目、使用仓库 Secrets 签名 release APK，并创建包含 APK、SHA-256 和 `latest.json` 的 GitHub Release。首次配置与发布步骤见 [`docs/GITHUB_RELEASES.md`](docs/GITHUB_RELEASES.md)。
